Binance Assistant

An independent personal cryptocurrency market research and analytics project.

Project Purpose

The application collects public cryptocurrency market data for statistical analysis, historical backtesting, market monitoring and portfolio risk research.

This project is not affiliated with or endorsed by Binance or any other cryptocurrency exchange.

Privacy Policy

Effective date: November 18, 2026.

This application is intended for personal use by its owner.

Google Drive access is used to store, retrieve, archive and synchronize research files and analytical reports.

Google user data is not sold or used for advertising. Access is limited to the functions necessary for project operation.

Authentication credentials are stored locally and are not intentionally published.

The owner can revoke Google account access and delete stored research files at any time.

Google API Data Usage

The application's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
